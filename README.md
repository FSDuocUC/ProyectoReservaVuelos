# Proyecto Reserva de Vuelos - Modelo ER

Este repositorio contiene el trabajo de la semana 8 del curso de Bases de Datos.  
Incluye el modelo entidad-relación diseñado en Oracle SQL Developer Data Modeler, junto con la documentación en Word.

## Contenido
- **Trabajo_ModeloER.docx** → Documento Word con:
  - Portada y objetivo del trabajo
  - Capturas de los diagramas en notación Barker y Bachman
  - Descripción breve de entidades y relaciones
  - Conclusión académica
- **ProyectoReservaVuelos.zip** → Archivo comprimido con:
  - El archivo `.dmd` del modelo
  - La subcarpeta generada automáticamente por Oracle SQL Developer Data Modeler

## Entidades principales
- **Pasajero**: almacena datos personales de los clientes.
- **Empleado**: contiene información laboral de los trabajadores.
- **Vuelo**: registra los vuelos programados.
- **Reserva**: centraliza las reservas realizadas, vinculando pasajeros, empleados y vuelos.

## Instrucciones de uso
1. Descargar el archivo `.zip`.
2. Descomprimirlo en una carpeta local.
3. Abrir el archivo `.dmd` con Oracle SQL Developer Data Modeler para visualizar el modelo.
